## ✨ Features

- 🎯 **Advanced GPA Forecasting**: Set target goals (e.g., *Xuất sắc*, *Giỏi*) and the app will reverse-calculate exactly what average scores you need for your remaining credits to achieve that degree classification.
- 📊 **Scale 10 & Scale 4**: Fully supports dual-scale GPA systems used across top Vietnamese universities.
- 🏫 **FPT University Ready**: One-click import for the standard FPT University curriculum (Software Engineering & IT), with automated credit mapping.
- ⌨️ **Keyboard-friendly Quick Add**: Rapidly log your semesters using fluid, spreadsheet-like inline editing (Tab & Enter navigation).
- 📁 **Import & Export**: Privacy-first. Your data is stored locally in your browser. Seamlessly back up to JSON or import multiple subjects via CSV.
- 🎨 **Glassmorphism UI**: A gorgeous, fluid, and responsive dark mode design with sleek micro-animations to keep you motivated.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Vanilla CSS with modern custom properties and flexbox/grid
- **Icons**: Lucide React
- **State Management**: React Context API & `useReducer`
- **Storage**: LocalStorage API
- **Deployment**: Vercel

## ⚙️ Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/theanhvb/GPA-Caculator.git
   ```
2. Navigate to the project directory:
   ```bash
   cd GPA-Caculator
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
